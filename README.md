# iwbtg - I Wanna Be The Guy

A simple clone of "I Wanna Be The Guy" built with HTML5 Canvas and JavaScript.

## How to Play

1. Open `index.html` in your web browser.
2. Use the following controls:
   - **Arrows / WASD**: Move
   - **Shift / Z**: Jump / Double Jump
   - **S**: Save at a checkpoint
   - **R**: Restart/Respawn

## How to Test

You can run automated tests for the game logic using Node.js:

```bash
node test_collision.js
```

## Features

- Unfair difficulty traps.
- Save points.
- Instant respawn.
- Death counter.
